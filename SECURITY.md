# Security and privacy

This project is a public educational guide. Its maintainers aren't an incident-response service and shouldn't receive passwords, tokens, wallet information, account screenshots or private audit logs.

## Documentation problems

For an inaccurate setting, broken source or risky recommendation, open an issue describing the guide section and the problem using a fictional example. Include the public vendor documentation that supports the correction.

Don't include a real account, device identity, organization configuration or credential. If the explanation needs sensitive evidence, don't post it in a public issue. Use an appropriate private reporting channel with the affected vendor or a specialist who can help.

## Personal incidents

Follow the affected provider's official recovery guidance. For civil-society and targeted-risk assistance, see [the getting-help guide](guides/getting-help.md). Don't send evidence to strangers who contact you through a public issue.

## Scope

The repository contains guidance and document-maintenance checks. Those checks do not audit a device or prove the absence of malware. Linked tools have their own security policies, release processes and licenses.
