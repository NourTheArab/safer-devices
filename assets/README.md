# Artwork and fonts

The cover and social-preview images are original typographic compositions rendered by [the artwork script](../scripts/build_artwork.py). They use the project's black, white, sand and olive palette. Alternative text in each README preserves the title and purpose outside the image.

The proposed social-preview image is prepared locally. It hasn't been uploaded to GitHub or set as a repository setting.

## Font licenses

Amiri, IBM Plex Sans Arabic and Newsreader come from the [official Google Fonts repository](https://github.com/google/fonts). Their original license notices are included:

- [Amiri: SIL Open Font License](fonts/amiri-OFL.txt).
- [IBM Plex Sans Arabic: SIL Open Font License](fonts/ibmplexsansarabic-OFL.txt).
- [Newsreader: SIL Open Font License](fonts/newsreader-OFL.txt).

The [provenance manifest](fonts/provenance.json) records original download locations and Git blob identities. WOFF2 versions were converted from those font files for self-hosted browser use. The original TTF files support reproducible artwork rendering. Font licenses apply separately from this repository's MIT license.

No font is installed into the operating system. The preview makes no requests to a font CDN. Thmanyah font files aren't redistributed here; their [current publisher license](https://font.thmanyah.com/licenses) restricts redistribution.
