# الفحص العملي: البداية مع أداة المساعدة

[English](../guides/practical-audit.md) · [الدليل الرئيسي](../README.ar.md)

هذه قائمة عمل فعلية، لا مجرد مواد للقراءة. تجمع فحص الجهاز وفحوص الحوادث ومتابعة الإصلاح. تاريخ المراجعة: **23 تشرين الأول 2026**. التنفيذ يقتصر على النطاق المسموح وما ينطبق على الجهاز. إصلاح جهاز آخر ليس وصفة جاهزة لهذا الجهاز.

## تحديد الوصول والنطاق مرة واحدة

البداية بقراءة [تعليمات المساعدة](agent-audit.md)، ثم مجموعة أسئلة قصيرة: الجهاز والنظام، وهل يخضع لإدارة العمل، والحسابات وملفات المتصفح المطلوبة، وأي حادث محتمل، وتوفر النسخ الاحتياطي، والتطبيقات التي يجب إبقاؤها بلا تغيير. كلمات المرور والمحافظ والأدوات الذكية محمية افتراضيًا؛ تحديث أداة ذكية يحتاج موافقة محددة أيضًا.

توضيح الوصول الفعلي: طرفية محلية، واجهة إعدادات، متصفح، فحوص شبكة، وصلاحية إدارة. بيئة بعيدة ليست لابتوب الشخص. صورة من هاتف لا تحدد الجهاز المطلوب فحصه. عند غياب الوصول المحلي، يبدأ [مسار المحادثة فقط](chat-only.md) مباشرة، مع [قائمة آيباد](ipad.md) عند اختياره، بلا تكرار طلب صلاحية لا يدعمها المنتج.

عند الاشتباه باختراق جارٍ أو استهداف، يسبق دليل [طلب المساعدة](getting-help.md) أي تنظيف. حفظ الأدلة أولًا، بلا تحديثات أو إزالة جماعية.

## استكمال جدول التغطية

لكل صف حالة: **تم التحقق**، **يحتاج انتباهًا**، **غير معروف**، أو **لا ينطبق**، مع الدليل والنطاق الدقيق. التحقق يخص الفحص المذكور، ولا يثبت مناعة البند من كل هجوم. غياب الوصول يبقى غير معروف. عدم الانطباق يحتاج سببًا. تعذر بند لا يوقف بقية العمل المسموح.

| الفحص | العمل والدليل | المتابعة |
|---|---|---|
| تحديث النظام والتطبيقات | إصدار النظام والبناء ونسخ المتصفحات والمراسلة والاجتماعات والشبكة الخاصة والأدوات الذكية، والتنبيهات الرسمية وإعادة التشغيل المعلقة. | تحديث النسخة المتأثرة بعد الموافقة، ثم إعادة قراءة الإصدار واختبار الاستخدام. |
| التشفير والقفل | حالة التشفير والمصادقة بعد السكون والدخول التلقائي وتوفر الاسترداد بشكل خاص. | اقتراح الإعدادات منفردة، بلا عرض مفتاح استرداد. |
| الجدار الناري والدخول عن بُعد | الحماية الواردة والدخول الآمن ومشاركة الشاشة والملفات. | سؤال عن الحاجة قبل التعطيل. |
| المنافذ والخدمات | مقابس TCP وUDP والبرنامج المسؤول ونطاق الارتباط. | الفصل بين الاتصال المحلي والاستماع على كل الواجهات والوصول الفعلي؛ لا إيقاف لعملية مجهولة. |
| النسخ والاستعادة | آخر نسخة مكتملة، واتصال الوجهة، ونجاح استعادة ملف تجريبي غير حساس. | الاستعادة تكتب ملفًا وتحتاج موافقة؛ الانفصال أو غياب التجربة يبقيان فجوة. |
| ملفات المتصفح | كل ملف مستخدم، والإصدار والإضافات والناشر والصلاحيات والحاجة. | اقتراح تعطيل إضافة واحدة مع خطة إعادة تفعيل؛ حماية مدير كلمات المرور والمحافظ. |
| الحسابات | آبل وغوغل وغيت هب ومايكروسوفت وبروتون حسب الموافقة، ثم الحسابات الأخرى المطلوبة. حالة المصادقة والاسترداد والجلسات ونطاق التطبيقات المتصلة. | الدخول والأسرار بيد جهة الاستخدام. البلد وحده لا يثبت الشك. إلغاء المنحة أو الجلسة المحددة بعد الموافقة. |
| التطبيقات المثبتة | الإصدارات والناشر والبرامج غير المستخدمة والمنتهية الدعم. | شرح أثر البيانات والاعتماديات، ثم إزالة قابلة للاستعادة عند الموافقة. |
| الصلاحيات الحساسة | تسهيلات الاستخدام وتسجيل الشاشة والوصول الكامل للقرص والموقع والكاميرا والميكروفون. | الحفاظ على احتياجات الإتاحة والسياسات المُدارة. |
| بدء التشغيل والاستمرارية | عناصر الدخول والخلفية أو تطبيقات بدء التشغيل والمهام المجدولة، وربطها ببرنامج وناشر معروفين. | الاسم غير المألوف ليس دليل خبث؛ لا حذف أو تفريغ تلقائي للخدمات. |
| بيئات التشغيل المضمّنة | نسخ Electron وNode وBun وPython وJava والتطبيقات المبنية بـ Go عند انطباقها، حتى بلا عمل برمجي. | تحديث الطرفية لا يصلح النسخة الخاصة داخل التطبيق؛ القناة الرسمية للتطبيق هي المرجع. |
| الثقة بالشهادات | [فحوص الحوادث](incident-checks.md) والضوابط لكل عميل متأثر. | صف مستقل لكل عميل ومخزن، وإعادة الفحص بعد تحديث النظام أو البيئة الموافق عليه. |
| المشاريع والحاويات | السؤال عن الاستخدام، ثم الاتفاق على المجلدات ومحرك محلي قبل الفحص. | لا تشغيل لجهاز افتراضي أو حاوية أو أوامر داخلها، ولا وصول لسياق بعيد أو تنزيل صور أو حذف بلا موافقة. |
| وصول الأدوات والمساعدات | الإضافات وخوادم MCP ونطاق الملفات والشبكة والأدوات عبر الحد الأدنى من بيانات الحالة. | لا قراءة لأسرار أو تفريغ إعدادات؛ تقليل الصلاحية يحتاج شرح أثره. |
| سياسة تثبيت التبعيات | داخل المشروع المتفق عليه، [سلامة الحزم](package-safety.md): الإصدارات والتبعيات والسكربتات والمصدر والإفصاح الخارجي. | لا تثبيت أو فحص خارجي افتراضيًا. موافقتان للإعداد والتثبيت، وتوقف عند التحذير أو المجهول أو فجوة التخزين. |
| التعرض وأدلة الحوادث | مطابقة التنبيهات الحالية وسجل مصدر البرنامج والتحقق من انتهاء الدعم. | الإصدار الضعيف لا يثبت الاستغلال. الحزمة الخبيثة المؤكدة تحتاج خطة استرداد وصلاحيات، لا تحديثًا فقط. |

## أوامر ماك المحلية للقراءة فقط

كل أمر فحص منفصل، وليس نصًا للتنفيذ الجماعي. الاعتماد على أدوات النظام الموثوقة. لا استخدام لـ `sudo` في المرور الأول؛ تعذر الصلاحية حد للتغطية. المسارات وأسماء الأجهزة والعناوين تبقى خاصة، والتقرير العام يقتصر على الحالة اللازمة.

```bash
/usr/bin/sw_vers -productVersion
/usr/bin/sw_vers -buildVersion
/usr/bin/fdesetup status
/usr/libexec/ApplicationFirewall/socketfilterfw --getglobalstate
/usr/bin/csrutil status
/usr/sbin/spctl --status
```

المتوقع تشفير مفعّل وجدار وارد مناسب وحماية سلامة النظام وفحص التطبيقات مفعّلان. الاستثناء المُدار يحتاج مراجعة تقنية المعلومات. النتيجة الغريبة تحتاج مقارنة بواجهة الإعدادات أو الاسترداد الرسمية؛ الطرفية المقيدة قد لا ترى الحالة الفعلية.

```bash
/usr/sbin/lsof -nP -iTCP -sTCP:LISTEN
/usr/sbin/lsof -nP -iUDP
```

نتيجة UDP مقابس مفتوحة، وليست كلها خوادم استماع. المطلوب هوية البرنامج ورقم العملية والمنفذ والارتباط، بلا معاملات تشغيل أو تاريخ اتصالات. العنوانان `127.0.0.1` و`::1` محليان؛ `*` و`0.0.0.0` و`::` أوسع. الوصول الفعلي يعتمد على الموجّه والشبكة الخاصة والجدار. لا مسح للشبكة المحلية أو الإنترنت. التحقق من **إعدادات النظام > عام > المشاركة** للدخول عن بُعد والمشاركة؛ المنفذ 22 وحده لا يثبت التعرض. [توثيق آبل](https://support.apple.com/guide/mac-help/allow-a-remote-computer-to-access-your-mac-mchlp1066/mac).

```bash
/usr/bin/tmutil latestbackup
```

قد يظهر مسار وجهة خاص؛ الملخص يقتصر على التاريخ والنجاح. خطأ اتصال أو تركيب القرص لا يثبت حذف النسخ. التأكيد من Time Machine، بلا تركيب تلقائي للأقراص. القفل والصلاحيات وعناصر الدخول والخلفية تُراجع في الإعدادات، لا بتفريغ قواعد التفضيلات. [دليل ماك](mac.md).

لفحص تطبيق مختار، استبدال المثال بموقعه المؤكد مع إبقاء علامات الاقتباس:

```bash
/usr/bin/plutil -extract CFBundleShortVersionString raw -o - '/Applications/Example.app/Contents/Info.plist'
/usr/bin/codesign --verify --deep --strict '/Applications/Example.app'
/usr/sbin/spctl --assess --type execute '/Applications/Example.app'
```

لا حاجة لتشغيل التطبيق لحصره. التوقيع الصحيح لا يثبت الحداثة أو السلامة الكاملة. النشر يقتصر على البيانات اللازمة؛ فشل التوقيع يحتاج تحقيقًا قبل الإزالة.

## أوامر ويندوز المحلية للقراءة فقط

البداية بجلسة PowerShell محلية عادية. اختيار حقول محددة يتجنب معرفات العتاد وسطر التشغيل. تعذر أمر أو وصول يبقى غير معروف. هذه ليست أوامر لطرفية لينكس.

```powershell
Get-CimInstance Win32_OperatingSystem | Select-Object Caption,Version,BuildNumber
Get-MpComputerStatus | Select-Object AMRunningMode,AntivirusEnabled,RealTimeProtectionEnabled,AntivirusSignatureLastUpdated
Get-NetFirewallProfile | Select-Object Name,Enabled
Get-BitLockerVolume | Select-Object MountPoint,VolumeStatus,ProtectionStatus
Get-Service sshd,TermService,WinRM -ErrorAction SilentlyContinue | Select-Object Name,Status,StartType
Get-NetTCPConnection -State Listen | Select-Object LocalAddress,LocalPort,OwningProcess
Get-NetUDPEndpoint | Select-Object LocalAddress,LocalPort,OwningProcess
```

هوية عملية مختارة بلا كشف معاملاتها، بعد استبدال الرقم التجريبي:

```powershell
Get-Process -Id 1234 | Select-Object Id,ProcessName
```

عمل خدمة لا يثبت قبولها اتصالًا عن بُعد. مراجعة **الإعدادات > النظام > سطح المكتب البعيد** والمشاركة وقواعد الجدار والملف الشبكي. قد يكون Defender في وضع سلبي تحت حماية مؤسسية أخرى؛ واجهة Windows Security توضح ذلك. استعلام التشفير قد يحتاج إدارة؛ إعادة المحاولة المرتفعة تتطلب موافقة، أو يكون البديل واجهة الإعدادات. لا اختيار لحقول مفاتيح الحماية.

ملف تنفيذي مختار:

```powershell
Get-AuthenticodeSignature -LiteralPath 'C:\Program Files\Example\Example.exe' | Select-Object Status
(Get-Item -LiteralPath 'C:\Program Files\Example\Example.exe').VersionInfo | Select-Object ProductVersion,FileVersion
```

التحديث وإعادة التشغيل وبدء التشغيل والمهام والصلاحيات تُراجع في الواجهة المعتادة. لا تفريغ لمعاملات إجراءات المهام. قائمة `Get-HotFix` وحدها لا تثبت اكتمال التحديث. المصادر: [حالة Defender](https://learn.microsoft.com/en-us/powershell/module/defender/get-mpcomputerstatus)، [بيانات TCP](https://learn.microsoft.com/en-us/powershell/module/nettcpip/get-nettcpconnection)، [دليل ويندوز](windows.md).

## البيئات والمشاريع: الحصر قبل التشغيل

البداية بالمواقع، بلا تشغيل ملف غير مألوف لمعرفة نسخته. قد تختلف نسخ مدير الإصدارات والبيئة الافتراضية والتطبيق والخدمة العاملة. البحث التالي عن الموقع لا يشغّل البرامج:

```bash
command -v node bun python3 uv java go php ruby tailscale
```

بعد إثبات المصدر، استعلام المسار المحدد بعلامة الإصدار الرسمية. في Python الخيار `-I -S --version`، وفي Java الخيار `-version`، وفي Go الأمر `version`. وسيط مدير الإصدارات قد يشغّل تهيئة؛ تحديد هدفه أولًا. لا استخدام لـ `npx` أو التثبيت أو `uv run` أو مهمة مشروع كاختصار للحصر.

في ماك، يسرد `/usr/libexec/java_home -V` بيئات Java المسجلة. فحص البيئات الخاصة داخل التطبيقات وأدوات التطوير المتفق عليها أيضًا، مع بقاء المسارات خاصة. الأمر `ps -p 1234 -o pid=,comm=,lstart=` يوضح البرنامج ووقت بدء عملية مختارة بلا معاملاتها. تحديث حزمة لا يعيد تشغيل العملية تلقائيًا.

للتطبيق المختار، فحص أسماء الملفات وموارد الإصدار داخل الحزمة بحثًا عن Electron أو Node أو Bun أو Python أو JDK. لا تشغيل للمساعدات أو طباعة متكررة لملفات الإعدادات والحزم، ولا استبدال لأطر موقعة. غياب دليل الإصدار يبقى فجوة.

في المشروع المتفق عليه، الاقتصار على بيانات الإصدارات ومدخلات ملفات القفل المتعلقة بالتنبيه. تضمين PHP وNext.js/sharp وStorybook وRuby/GitLab عند وجودها. لا فتح لملفات الأسرار أو بيانات الحزم أو عناوين مستودعات خاصة. المرجع [فحوص الحوادث](incident-checks.md) و[أدوات التطوير](developers.md).

للحاويات، تحديد نقطة اتصال السياق بشكل خاص والتأكد أنها محلية أولًا. المحرك المتوقف يبقى متوقفًا. بعد الاتفاق على النطاق:

```bash
docker ps --format '{{.ID}}\t{{.Image}}\t{{.Ports}}'
docker image ls --digests --format '{{.ID}}\t{{.Repository}}:{{.Tag}}\t{{.Digest}}'
docker inspect --format '{{.HostConfig.Privileged}} {{.HostConfig.NetworkMode}} {{json .HostConfig.PortBindings}}' CONTAINER_ID
```

استبدال المعرف المختار. الربط بالمضيف ومقبس Docker يُراجعان كبيانات خاصة، مع تقرير نوع الوصول دون مسارات. لا تفريغ كامل للفحص أو البيئة أو السجل أو الملصقات. مطابقة البصمة مع تنبيه الناشر لازمة؛ الوسم لا يكفي. الفحص بحزمة أخرى أو البناء أو `docker exec` يحتاج موافقة مستقلة. [أمان Docker](https://docs.docker.com/engine/security/).

## من النتائج إلى إصلاح متحقق

استخدام [خطة الإصلاح](repairs.md). الأولوية للتعرض المعروف والبرمجيات المنتهية الدعم، ثم الوصول الزائد وفجوات الاسترداد. الحساب المحجوب لا يعطل بقية الفحص.

الخاتمة جدول تغطية، ثم **ما تغيّر، وما تم التحقق منه، والمجهول، والمؤجل، وما يحتاج قرارًا، والتراجع**. تسمية إعادة التشغيل والنسخ المنفصلة والتطبيقات المنتظرة لتصحيح. لا جدولة أو إلغاء وصول بلا موافقة. [سيناريوهات التحقق من عمل الأداة](agent-verification.md) تقيس السلوك المطلوب، لا جمال الإجابة فقط.
