# فحوص الحوادث والتحقق من بيئات التشغيل

[English](../guides/incident-checks.md) · [الفحص العملي](practical-audit.md)

تاريخ المراجعة: **23 تشرين الأول 2026**. هذه لقطة مؤرخة. كل فحص جديد يبدأ بمراجعة التنبيهات الأصلية وتسجيل التاريخ ومطابقة المنتج والمنصة والفرع. الروابط لا تمنح صلاحية لتشغيل الشيفرة.

## eMudhra: فحص العميل الفعلي، لا المتصفح فقط

البداية من [تقرير موزيلا](https://blog.mozilla.org/security/2026/10/20/protecting-firefox-users-following-the-compromise-of-emudhra-intermediate-certificates/) و[مواقع الفحص للحادث](https://emudhra.we-have-a-problem.com/). قد تختلف مخازن الشهادات وآليات الحظر بين العملاء. الفحص يقيس قبول سلاسل الشهادات العامة للحادث، ولا يرسل استغلالًا.

هذه النسخة تشمل أربع عشرة سلسلة، ومنها موقعان بلا تسجيل شفافية شهادات. الإصلاح السابق لا يثبت تغطية كل سلسلة حالية أو كل تطبيق. لا نسخ لتقارير خاصة أو إعدادات ثقة من لابتوب آخر.

### موافقة مستقلة على اتصالات الفحص

قراءة [نطاق الأداة](tls-probe.md) ومصدرها أولًا. مواقع الفحص وخادم DNS يمكنها رؤية بيانات اتصال مثل عنوان المصدر. لا حاجة لأسرار أو ملفات تعريف ارتباط أو رؤوس شخصية أو رفع تقرير. اتصالات Python وNode وBun مباشرة وقد لا تتبع وكيل HTTP المؤسسي؛ لا تجاوز لسياسة شبكة مطلوبة. البديل مسار مسموح أو نتيجة غير معروفة.

يتطلب المشغّل Python موثوقًا ومثبتًا مسبقًا، من الإصدار 3.9 فما بعد. التثبيت يحتاج موافقة مستقلة. من جذر المستودع وبعد الموافقة على الشبكة:

```bash
python3 -I -S checks/tls_probe.py --allow-network
python3 -I -S checks/tls_probe.py --allow-network --client curl --executable /usr/bin/curl
```

الأول يفحص سياق SSL الافتراضي لبيئة Python المشغلة فقط. الثاني يفحص نسخة curl المحددة. في ويندوز، المسارات هي المسارات الموثوقة الفعلية لذلك الجهاز. غياب Python يعني بديلًا يدويًا أو أداة بموافقة، لا تثبيتًا تلقائيًا.

لكل نسخة Node أو Bun موثوقة، استبدال المسار التجريبي بالمسار المطلق الموافق عليه:

```bash
python3 -I -S checks/tls_probe.py --allow-network --client node --executable /absolute/approved/node
python3 -I -S checks/tls_probe.py --allow-network --client bun --executable /absolute/approved/bun
```

المثال لا يسمح بتشغيل ملف مجهول. فحوص Python وNode وBun مصافحة TLS دون تنزيل محتوى HTTP. يرسل curl طلب HEAD بلا ضغط أو تحويل، مع تعطيل ملف إعداد بدء التشغيل. لا إضافة لـ `-k` أو `--insecure` أو أي تجاوز للتحقق.

### تفسير الدليل

يلزم نجاح موقعين سليمين ورفض موقع بشهادة ذاتية التوقيع قبل احتساب مواقع الحادث الأربعة عشر. انتهاء المهلة أو فشل DNS أو TLS عام أو ضابط محجوب يعني **غير معروف**.

| رمز الخروج | المعنى | الإجراء |
|---|---|---|
| 0 | رفض السلاسل الأربع عشرة بعد نجاح الضوابط. | تسجيل `verified_for_tested_chains` للعميل والمسار الشبكي المحددين فقط. |
| 1 | قبول سلسلة واحدة على الأقل بعد نجاح الضوابط. | يحتاج انتباهًا، مع تحديد العميل والمخزن وخطة الإصلاح. |
| 2 | فشل ضابط أو نتيجة ناقصة أو استدعاء غير صالح. | غير معروف، مع قراءة السبب؛ لا تصنيف كنجاح. |

قد ينتج رفض الشهادة عن انتهاء الصلاحية أو منتج وسيط أو سلسلة أخرى، لا عن الحظر المقصود وحده. الأداة لا تقارن بصمات السلسلة المقدمة حيًا. النتيجة المفاجئة تحتاج تنبيهًا حاليًا وطريقة ثانية مسموحة. لا نتيجة تثبت سلامة الماضي أو البرامج الأخرى.

صف مستقل لكل curl للنظام، وApple URLSession، وPython وبيئاته المستخدمة، وpip وuv وNode وBun وJava والتطبيقات المبنية بـ Go والتطبيقات ذات الصلة. الصف غير المفحوص يبقى مجهولًا. الأداة **لا تفحص** مخزن pip المضمّن أو requests/certifi أو uv أو Java أو ملفات Go أو الحاويات أو Apple URLSession.

### تغطية المخازن الأخرى بأداة متخصصة بموافقة

يوفر [Wardlatch](https://github.com/deimos-hq/wardlatch) فحوص عملاء إضافية. مراجعة المصدر والإصدار والخيارات الحالية أولًا، ثم الاتفاق على نسخة ومصدر محددين؛ لا استخدام صامت لـ `latest`. وصف الصيانة للسلوك الشبكي والحاويات ليس تدقيقًا مستقلًا.

بعد التحقق الفعلي من تطابق إصدار الحزمة ومصدرها، يكون الأمر التالي اقتراح تثبيت وتشغيل، مع استبدال `REVIEWED_VERSION` والمجلد المسموح الموجود فعلًا. يحتاج موافقة وليس من المرور الأول:

```bash
npx --yes wardlatch@REVIEWED_VERSION --incident emudhra-2026-10 --no-containers --paths /absolute/approved/folder --json
```

لا تنفيذ للنص التجريبي. التأكد من مصدر تلك النسخة أن الخيارات تقيد النطاق كما هو مقصود. تعطيل الحاويات يتجنب سياقًا بعيدًا أو أوامر داخل حاوية. اختيار الحادث يمنع الموافقة الضمنية على فحوص أسرار ورؤوس ومستودعات أوسع. مراجعة التغطية الفعلية؛ لا افتراض العثور على كل بيئة أو JDK خاص. بيئة مشتبه باختراقها لا تُشغّل للفحص؛ بيانات التوزيع ودعم الحوادث هما المسار المناسب.

للعميل غير المغطى، إعداد فحصه الأصلي كاقتراح محدود مع ضوابط نجاح ورفض. الفحص المفقود فجوة صريحة، لا سبب لتسمية التطبيق آمنًا.

## Brotli وNode وBun المضمّن

[إصدار Node الأمني](https://nodejs.org/en/blog/vulnerability/october-2026-security-releases) يشرح مشكلة مفك الضغط ومشكلات أخرى. مطابقة الفرع المثبت بالتصحيح الحالي. التطبيق المضمّن يحتاج إصدارًا من ناشره حتى مع تحديث الطرفية. في Bun والأدوات المرتبطة، مراجعة [المشكلة الأصلية](https://github.com/oven-sh/bun/issues/46352) وإصدارات الناشر قبل تحديد التعرض.

هذا مؤشر دون شبكة لملف مختار، لا يشغّل الهدف. استبدال المثال بالمسار الموافق عليه، بلا مسح متكرر للمجلدات:

```bash
python3 -I -S - '/absolute/approved/binary-or-library' <<'PY'
from pathlib import Path
import sys
data = Path(sys.argv[1]).read_bytes()
print('control_count', data.count(b'FORMAT_EXUBERANT_NIBBLE'))
print('fix_count', data.count(b'FORMAT_BLOCK_SWITCH'))
PY
```

البحث عن نصين ليس اختبار استغلال. الملف المضغوط أو المنقّح قد لا يحتويهما. المؤشر لا يثبت السلامة؛ يلزم مصدر الحزمة وإصدارها والمكتبة المرتبطة والتنبيه. الملف الكبير يحتاج حدًا للحجم أو بحثًا متدفقًا موثوقًا. لا تنزيل لحمولة ضغط خبيثة للتجربة.

## Go وJava وPython وأدوات الحزم

| المكوّن | الفحص العملي | الإصلاح والتحقق |
|---|---|---|
| Go | أمر `go version` للنسخة الموثوقة، ومطابقة [سجل الإصدارات](https://go.dev/doc/devel/release)، مع حصر التطبيقات المبنية به منفصلة. | تحديث مترجم مدعوم بعد الموافقة. الملفات القائمة تحتاج عادة إعادة بناء أو تحديث ناشرها؛ تثبيت المترجم وحده لا يستبدلها. |
| Java | حصر البيئات المسجلة والخاصة بالتطبيقات والناشر والدعم ونتيجة المخزن. مراجعة [تنبيه الناشر](https://www.oracle.com/security-alerts/alert-cve-2026-91403.html). | تحديث مناسب من الناشر، ثم اختيار البيئة وإعادة تشغيل العمليات التابعة عند الموافقة. الحداثة وحدها لا تثبت معالجة الثقة. |
| Python وpip وuv | كل بيئة مستخدمة ومصدر المفسر وأداة التثبيت؛ بيانات الحزمة قبل تشغيل ما يثير الشك. [تغييرات pip](https://pip.pypa.io/en/stable/news/) و[إصدارات uv](https://github.com/astral-sh/uv/releases). | تحديث البيئة المحددة بمديرها، ثم إعادة اختبار العميل الفعلي؛ تحديث certifi لا يساوي بالضرورة تحديث مخزن pip. |
| Tailscale أو برنامج شبكة مبني بـ Go | بيانات التطبيق والخدمة مقابل [تنبيهات الناشر](https://tailscale.com/security-bulletins). | تحديث التطبيق والخدمة العاملة عبر المسار الرسمي مع موافقة إعادة التشغيل. |

## الخوادم والتعرض عبر توريد البرمجيات

الفحص بحسب الاستخدام. نطاق اللابتوب لا يسمح بخادم بعيد أو إنتاج. لكل بند تنبيه منطبق أو سبب عدم الانطباق:

| المجال | الدليل والمصدر | القرار |
|---|---|---|
| PHP | بيانات البيئة العاملة لطلبات الويب وبناء الناشر و[إعلانات PHP](https://www.php.net/archive/2026.php)، ومنها متابعة 23 تشرين الأول. | جهة تشغيل الموقع تعالج الخادم وتتحقق من إعادة العمال؛ نسخة الطرفية وحدها لا تثبت نسخة الخدمة. |
| Next.js/sharp وStorybook | إصدارات التبعيات وملفات القفل المختارة مقابل [تنبيه Next.js](https://nextjs.org/blog/nextjs-security-update-october-14-2026) و[تنبيه Storybook](https://github.com/storybookjs/storybook/security/advisories/GHSA-f2ph-cmg5-wxc8). | تحديث معتمد للتبعيات واختبار ونشر التطبيق المتأثر؛ لا تشغيل لخطافات التثبيت لمجرد الحصر. |
| GitLab ذاتي الإدارة وRuby | بيانات تثبيت الناشر مقابل [إرشادات GitLab](https://docs.gitlab.com/releases/patches/patch-release-gitlab-19-5-1-released/) و[تنبيه Ruby](https://www.ruby-lang.org/en/news/2026/10/23/regexp-fixes-for-gitlab-cves/). | القرار لجهة تشغيل محددة وخطة صيانة؛ لا تغيير بعيد ضمنيًا. |
| حزم محتملة الخبث | هوية المنتج والإصدار والملف مقابل تنبيه الناشر، مثل [OVHcloud CLI](https://github.com/ovh/ovhcloud-cli/security/advisories/GHSA-862f-55f5-vmvw) أو [LiteLLM](https://docs.litellm.ai/blog/security-incident-oct-21-2026). | لا تشغيل لمعرفة النسخة. حفظ الأدلة وخطة استرداد الصلاحيات من جهاز موثوق عند تأكيد التعرض. |
| خدمات مخترقة وأتمتة المستودعات | السؤال عن الخدمات وأنواع بيانات الاعتماد المخزنة، بلا قيم. مراجعة صلاحيات ملفات العمل المختارة والتغييرات والإجراءات الخارجية غير المثبتة. | مطابقة التنبيه المؤرخ والموافقة على كل إلغاء أو تدوير مع الاسترداد؛ لا مسح لقيم الأسرار أو التاريخ بلا نطاق منفصل. |

هذه مسارات تحقيق، وليست ادعاءً بتأثر كل تثبيت. الحوادث الجديدة تحتاج تحديثًا مؤرخًا ومراجعًا. [قائمة Dom](https://github.com/dominikmartn/black-october-check) ألهمت النهج؛ أوامرها مواد خارجية للمراجعة، لا تفويضًا عامًا.
