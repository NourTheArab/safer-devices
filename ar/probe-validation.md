# سجل التحقق من فاحص الشهادات

[English](../checks/VALIDATION.md) · [نطاق الأداة](tls-probe.md)

التاريخ: **23 تشرين الأول 2026**. السجل لاختبار الأداة أثناء التطوير، وليس تقييمًا أمنيًا لشخص أو جهاز. لا نشر لتقارير خاصة أو حسابات أو معرفات أجهزة أو عناوين شبكة.

## الاختبارات الآلية

نجاح **24 اختبارًا** للتوثيق وضوابط TLS والحكم والمهل وتصنيف أخطاء الشهادات وبوابات التنفيذ والشبكة وقيود بدء Bun ومحاكاة أحداث Node بلا شبكة. استجابات النقل محاكاة؛ بيئة اختبار Node تستبدل وحدة TLS ولا تفتح مقابس. CI ينفذ هذه الاختبارات دون اتصال خارجي.

## تجربة المواقع العامة

عملاء مختارون في بيئة تطوير macOS، مع موافقة الشبكة. النجاح يتطلب اتصال الضابطين السليمين ورفض الشهادة الذاتية وكل سلاسل الحادث الأربع عشرة:

| العميل | النسخة المجربة | الملاحظة |
|---|---|---|
| SSL الافتراضي في Python | 3.13.2 | نجاح الضوابط؛ 14 مرفوضة، بلا قبول أو مجهول. |
| curl للنظام | 8.7.1 | نجاح الضوابط؛ 14 مرفوضة، بلا قبول أو مجهول. |
| Node منفصل | 26.12.1 | المرور الأول: ضابط سليم غير حاسم، فتجاوز مواقع الحادث وخروج 2. اتصال لاحق للضابط نجح، ثم إعادة كاملة رفضت 14 سلسلة. لم يُحدد سبب الفشل الأول. |
| Bun منفصل | 1.4.4 | النسخة النهائية مع `--no-env-file --no-install`: نجاح الضوابط ورفض 14 دون قبول أو مجهول. |

هذه ملاحظات لذلك المسار والتاريخ. لا تقارن الأداة بصمة السلاسل المقدمة؛ الرفض لا يثبت بشكل مستقل الحظر المقصود للمفتاح. لم تُنزّل حمولة خبيثة ولم تغيّر الأداة إعدادات أمان.

## ما لم يُختبر

لا تجربة فعلية في ويندوز أو لينكس أو iPadOS أو نسخ عملاء أخرى أو شبكة مؤسسية ملزمة بوكيل، ولا تحقق حي لـ Java أو ملف Go أو pip/uv أو Apple URLSession أو بيئة مضمّنة أو حاوية ضمن هذه التجربة. الأدلة تطلب فحصًا مناسبًا أو مجهولًا صريحًا أو سبب عدم الانطباق. إصدار أو موقع أو شبكة جديدة تحتاج مراجعة وتجربة جديدة.

سيناريوهات قبول الأداة حالات مراجعة مكتوبة، لا معيارًا آليًا يثبت التزام كل مساعد. فحوص المستندات تتحقق من البنية والروابط المحلية، لا توفر التنبيهات الخارجية مستقبلًا أو وقوع فحص جهاز صديق.
