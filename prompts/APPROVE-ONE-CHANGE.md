# Approve one change

[العربية](../ar/approve-one-change.md)

Ask the agent to complete this form before you say yes:

| Question | What you should see |
|---|---|
| What exactly changes? | The named app, setting, account grant, service, or file. |
| Why? | Current evidence, an official source where relevant, and the expected benefit. |
| What might stop working? | A concrete feature or dependent service, including possible restarts. |
| What stays protected? | Passwords, recovery options, wallets, other accounts and unrelated projects. |
| How can I undo it? | A recoverable backup, a precise reversal, or an honest explanation that rollback is limited. |
| How will we check it? | A resulting setting/version check and a normal workflow test. |

Then send a narrow instruction, for example:

```text
I approve disabling the unused coupon extension we just reviewed, in the
browser profile we identified. Keep its data, every other extension, my
password manager, and my wallets untouched. Verify it is disabled afterward.
This approval does not cover any other change.
```

Some actions still need you at the keyboard: signing in, adding authentication methods, entering administrator credentials, and saving recovery codes. Keep those steps private.
