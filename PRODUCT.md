# Safer Devices product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Friends and family who want understandable device and account security steps. AI agents can help interpret and check the guidance with the owner's permission.

## Product Purpose

A shareable public GitHub guide with a useful first checklist, deeper guides, copyable agent instructions and attributed sources. Success means readers can choose a relevant check, understand its limits and verify an approved change.

## Capabilities and Constraints

This is educational documentation, not a scanner, installer or incident-response service. Preserve privacy, recovery options, narrow approvals and the distinction between verified and unknown results. Never include private device-audit data.

The owner approved public GitHub publication on 23 October 2026. The reading preview remains a local development tool. GitHub controls README typography and page layout; custom visual assets must work within those limits.

## Brand Commitments

The owner requested an Arabic, Nawafith-inspired treatment and a polished GitHub repository. English opens first, with Arabic one click away. The existing security content and sources remain the basis of both editions.

## Evidence on Hand

The English guides, source list and agent prompts are in this repository. There are no security certifications, customer counts or independent software-audit claims to display.

## Product Principles

- Start with a small set of useful checks.
- Check, explain, obtain approval, change and verify.
- Keep sensitive material with its owner.
- Show sources and uncertainty together.
