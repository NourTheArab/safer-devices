# Browsers and extensions

[العربية](../ar/browsers.md)

An extension is software inside your browser. Depending on its permissions, it may access the pages you read or interact with. Keep a small set you recognize and use.

## Review each profile

Check the browser's update screen and restart after saving work. Then open its extension manager. Do this separately for personal, work, and other profiles; their extensions can differ.

| Browser | Where to start |
|---|---|
| Chrome, Edge, Brave, Opera | Menu > Extensions > Manage extensions. Open each extension's details. |
| Firefox | Menu > Add-ons and themes > Extensions. Review Details and Permissions. |
| Safari | Safari > Settings > Extensions. |

Settings vary by version. Use [Chrome's extension instructions](https://support.google.com/chrome/answer/2664769?hl=en) and [Mozilla's permission guide](https://support.mozilla.org/en-US/kb/permission-request-messages-firefox-extensions) for the exact controls.

## What to look for

- Do you recognize the extension and still need it?
- Is the publisher the one you intended? A familiar name, store listing, or high rating alone doesn't establish that.
- Can it read every website, browsing history, downloads, or local files? Does that match its purpose?
- Can it run in private windows? Review that separately; [Firefox explains private-window access](https://support.mozilla.org/en-US/kb/extensions-private-browsing).
- Is it managed by your employer? Ask IT before changing organization policy.

Broad access can be necessary for a password manager, accessibility tool, or browser-control agent. It isn't proof of malware. Decide whether the feature is worth the access.

## Make reversible changes

For an ordinary extension you no longer need, disabling it first preserves a simple recovery path. Where supported, narrow website access or remove optional permissions. Check that the feature you wanted still works.

**Leave password-manager and wallet extensions, their profiles, and their storage untouched during routine cleanup.** Recovery and migration must be verified privately before any separate removal decision. Don't use a browser-profile reset as a shortcut.

An agent extension also needs a permissions review in the agent's own settings. Browser capability and the agent's permission to act are separate controls. Keep approval prompts for sensitive sites. OpenAI documents its browser-control permissions and site controls in [its extension guide](https://learn.chatgpt.com/docs/chrome-extension).

## Keep reports small

Record extension names, versions, enabled state, publisher/source, and relevant permissions. Don't export cookies, extension storage, saved passwords, wallet data, or browsing history for a routine inventory.

**Finished:** every checked profile is named, unnecessary access has been reduced with approval, protected extensions still work, and unchecked profiles remain marked unknown.
